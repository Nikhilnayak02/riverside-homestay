# Jungle Homestay

A static website for a riverside homestay project.

## Project structure

- `index.html` — main homepage
- `css/styles.css` — site styling
- `js/main.js` — small page interaction script
- `assets/` — place images and other media here if needed

## Usage

Open `index.html` in a browser to view the site.
